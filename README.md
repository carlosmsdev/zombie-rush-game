Zombie Rush

Estou começando a programar esse jogo para praticar e aprender mais sobre programação !

Zombie Rush é um jogo 2D de sobrevivência que estou começando a desenvolver com **Phaser**, **TypeScript** e **Vite**.

O objetivo é sobreviver ao maior número possível de ondas de zumbis, utilizando diferentes armas

Versão atual
v0.1.0 — Primeira versão jogável**

Funcionalidades
- Movimentação com WASD
- Mira controlada pelo mouse
- Sistema de tiros
- Pistola
- Rifle
- Shotgun
- 3 tipos de zumbis
- Sistema de vida
- Barra de HP
- Pontuação
- Recorde salvo localmente
- Ondas progressivas
- Aumento de dificuldade
- Game Over
- Reinício da partida

Controles
 W  = Mover para cima
 A  = Mover para esquerda 
 S  = Mover para baixo 
 D  = Mover para direita 

 Clique esquerdo = Atirar 
| 1 | Pistola
| 2 | Rifle 
| 3 | Shotgun 
| R | Reiniciar após Game Over 

Armas
Pistola
Arma equilibrada para combate geral.

Rifle
Possui maior velocidade de disparo e projéteis mais rápidos.

Shotgun
Dispara vários projéteis simultaneamente com espalhamento.

Inimigos

Zombie Normal
Inimigo equilibrado em vida, velocidade e dano.

Zombie Fast
Possui menos vida, porém se movimenta rapidamente em direção ao jogador.

Zombie Tank
Possui muita vida e causa maior dano, porém se movimenta mais lentamente.
